# Tableau dashboard

`sales_forecasting_dashboard.twbx` is a packaged Tableau workbook with one dashboard and nine sheets. It embeds the CSV files in `Data/`, so it opens without any file paths to fix.

## Open it (Windows or macOS)

1. Install **Tableau Public** (free): https://public.tableau.com/app/discover → "Download Tableau Public". Tableau has no Linux desktop version.
2. Double-click `sales_forecasting_dashboard.twbx`, or use File → Open.
3. Click the **Retail sales forecasting dashboard** tab at the bottom.
4. Set the dashboard size to Automatic if the window is smaller than 1500 px (Dashboard pane, Size).

## Publish it and get the link

1. File → Save to Tableau Public As… and sign in (or create a free account).
2. Name it `Retail Sales Forecasting`. The browser opens the published dashboard.
3. Put the public link and a screenshot in the project README.

Public workbooks are visible to everyone, and the data in them can be downloaded. These CSVs are small summaries of the Kaggle data, so that is fine.

## If something looks wrong

* **"Cannot open workbook" error:** the workbook was generated by `build_workbook.py` and checked against Tableau's published schema, but never opened in Tableau itself. Use the manual build below.
* **A chart is blank or a sheet shows a red `!`:** open that sheet and check the fields on Rows/Columns match the table above. Right-click the data source → Edit Data Source if Tableau asks you to locate a CSV, and pick the file in `Data/`.
* **Store filter missing:** on the dashboard, click the Store ranking sheet → the dropdown arrow → Filters → state.

## Manual build (about 30 minutes)

Connect to Text file, one CSV at a time (Data → New Data Source), and build:

1. **KPI tiles**: `kpi_tiles.csv`. One sheet per column: drag the column to Text, then format the number.
2. **Actual vs forecast**: `holdout_long.csv`. `date` (continuous Day) to Columns, `sales` (Sum) to Rows, `model` to Color. Mark type Line.
3. **Day of week / month**: put `day` (or `month`) on Columns and `avg_daily_sales` on Rows. Sort the dimension by `day_num` (or `month_num`) ascending, aggregation Minimum.
4. **Families**: `sales_by_family.csv`. `family` on Rows, `sales` on Columns, sort descending.
5. **Stores**: `sales_by_store.csv`. `store` on Rows, `sales` on Columns, sort descending. Drag `state` to Filters, show the filter.
6. **Dashboard**: new dashboard, size 1500 x 1700, drag the sheets in and add the caption: "Single 90-day holdout (2017-05-18 to 2017-08-15), not walk-forward validation."

## Regenerating

The notebook's last cell exports the raw summaries; `prepare_data.py` derives the dashboard CSVs from them. To rebuild the workbook after changing the CSVs:

```bash
pip install lxml
python prepare_data.py
python build_workbook.py            # packages the .twbx
python build_workbook.py path/to/twb_2026.1.0.xsd   # also validates against the schema
```

The schema is published at https://github.com/tableau/tableau-document-schemas.
